# 📖 CSS Grid - Images Magazine Layout

This project is a simple **CSS Grid practice project** designed to showcase how powerful CSS Grid can be for creating magazine-style layouts. The page highlights featured and standard articles with images, titles, and short descriptions, wrapped inside a responsive grid system.

---

## 🚀 Features
- **Responsive Layout** built using CSS Grid  
- **Magazine-style design** with a featured article spanning larger space  
- **Semantic HTML5 structure** (`header`, `main`, `article`, `footer`)  
- **Custom styling** to create an elegant and clean reading experience  

---

## 🛠️ Technologies Used
- **HTML5** – for semantic structure  
- **CSS3 (CSS Grid + Flexbox)** – for layout and styling  
- **Responsive Design Principles** – making it adapt across devices
